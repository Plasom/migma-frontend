# หลังบ้านสองภาษา (13 ต.ค. 2026)

- หลังบ้านและหน้าบัญชีเปิดเป็นภาษาอังกฤษเป็นค่าเริ่มต้น สลับเป็นไทยได้ 3 จุด: ใต้ฟอร์มเข้าสู่ระบบ, ตั้งค่า › การแสดงผล, หน้าต่างวิธีใช้
- ค่าที่เลือกเก็บใน localStorage `pf-ui` (`en` | `th`) แยกจากภาษาของเว็บ (`site.base`, `site.i18n`) และภาษาที่กำลังกรอก (`pf-edlang`)
- ไฟล์ใหม่ `src/preview/js/ui-i18n.js`: ข้อความต้นฉบับในโค้ดยังเป็นไทย ไฟล์นี้แปลข้อความที่ขึ้นจอเป็นอังกฤษตอนแสดงผล (ตารางคำตรงตัว `UI_EN`, ข้อความที่มีค่าแทรก `UI_TPL` / `UI_RULES`) ไม่แตะค่าที่ผู้ใช้พิมพ์ในช่องกรอก
- เพิ่มข้อความใหม่ในระบบ ต้องเพิ่มคำอังกฤษในไฟล์นี้ด้วย หาคำที่ตกหล่นได้โดยตั้ง `localStorage['pf-ui-miss']='1'` แล้วใช้งาน รายการจะสะสมใน `pf-ui-missed`
- ยังไม่แปล: รายการแนะนำที่เป็นเนื้อหาของเว็บ (ตำแหน่ง ทักษะ มหาวิทยาลัย คณะ วุฒิ เกียรตินิยม) ซึ่งตามภาษาของเว็บ ไม่ใช่ภาษาหลังบ้าน, ข้อความตัวอย่างที่ AI จำลองร่างให้
- ตอนทำจริงควรย้ายเป็นไฟล์ภาษาแบบ key ต่อข้อความ (เช่น i18next) ใช้ `UI_EN` เป็นต้นฉบับคำแปลได้เลย
