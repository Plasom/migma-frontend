|---|---|---|
| Dropdown menu | รายการ**คำสั่ง** (แก้ไข, ทำสำเนา, ลบ) หรือเลือกค่า 1 อย่าง | ได้ · เลือกแล้วปิด |
| Popover | กล่อง**เนื้อหาเล็ก**ที่ทำต่อได้ (แชร์ลิงก์, ตัวกรองย่อย, รายละเอียดสั้น) | ได้ · ปิดเมื่อกดนอก/Esc |
| Tooltip | **ชื่อ/คำอธิบาย**ของปุ่มไอคอน หรือคำย่อ | ไม่ได้ · อ่านอย่างเดียว |
ข้อมูลสำคัญห้ามอยู่ใน tooltip อย่างเดียว (มือถือไม่มี hover) · ฟอร์มยาวไม่ใส่ popover (ใช้ dialog/sheet)

## Dropdown menu
- พื้น `--raised` (dark ยกขึ้นจากการ์ด) · มุม 14 · padding 6 · เงา elevation-3 · ไม่มีเส้นขอบ · กว้าง 200–320 · ห่างปุ่ม 6
- แถว 40 · ตัว 14 · ไอคอน 18 สี text-2 (ใช้ทุกแถวหรือไม่ใช้เลย) · แถบ hover/โฟกัส **ทรง pill** สี `--muted-hover`
- เส้นคั่น 1px เว้นซ้ายขวา 12 · แบ่งกลุ่มคำสั่ง · คำสั่งอันตรายอยู่**ล่างสุด**แยกกลุ่ม สีแดง (hover พื้นแดงอ่อน)
- เปิด: จาง + เลื่อน 4px 160ms จากมุมที่ใกล้ปุ่ม · ปิด 120ms · ชนขอบจอ → พลิกขึ้น/ซ้ายเอง

### ปุ่มลัด (shortcut)
- แสดงชิดขวา ตัว 12 สี `--menu-kbd-fg` (text-2) · tabular-nums · ห่างข้อความอย่างน้อย 16 · hover แล้วสีไม่เปลี่ยน
- **ใส่เฉพาะคำสั่งที่มีปุ่มลัดใช้ได้จริง** ไม่ใส่ทุกแถวให้ดูครบ · แถวที่ไม่มีปุ่มลัดเว้นว่าง
- Mac แสดงสัญลักษณ์ `⌘ ⇧ ⌥ ⌫` · Windows/Linux แปลงเป็น `Ctrl+ Shift+ Alt+ Del` อัตโนมัติ (เก็บค่าจริงใน `data-kb`)
- มือถือ/จอสัมผัส: ซ่อนได้ (ไม่มีคีย์บอร์ด) · ปุ่มลัดเป็นข้อมูลเสริม ห้ามเป็นที่เดียวที่บอกว่าคำสั่งทำอะไร

### เมนูย่อย (หลายชั้น)
- แถวที่มีเมนูย่อย: ไอคอน `chevron_right` ท้ายแถว · `aria-haspopup="menu"` + `aria-expanded` · ตัวแถวเองไม่ใช่คำสั่ง (กดแล้วเปิดเมนูย่อย ไม่ปิดเมนู)
- **ลึกสุด 2 ชั้นย่อย** (เมนูหลัก › ชั้น 1 › ชั้น 2) · ลึกกว่านี้ให้ย้ายไป dialog/sheet
- **คำสั่งอันตรายไม่อยู่ในเมนูย่อย** (ลบต้องเห็นจากเมนูหลัก)
- เปิดด้านขวา ห่าง `--menu-sub-offset` 2px · ขอบบนของเมนูย่อยตรงกับแถวที่เปิด · ชนขอบขวา → พลิกไปซ้าย
- ระหว่างเปิด แถวแม่ค้างพื้น `--menu-item-hover` ให้รู้ว่ามาจากไหน
- เมาส์: ชี้ค้าง 100ms เปิด · ออก 250ms ค่อยปิด (กันหลุดตอนลากเฉียงไปเมนูย่อย) · ชี้แถวอื่นในชั้นเดียวกัน = ปิดเมนูย่อยเดิม
- คีย์บอร์ด: `→` / Enter / Space เปิดและโฟกัสแถวแรก · `←` / Esc ปิดชั้นนั้นแล้วโฟกัสกลับแถวแม่ · `↑↓` วนในชั้นเดียว · Tab ปิดทั้งหมด
- เลือกคำสั่งในชั้นไหนก็ตาม = ปิดทุกชั้น แล้วโฟกัสกลับปุ่มที่เปิดเมนู
- **มือถือ (≤600)**: ไม่เปิดด้านข้าง · กางลงด้านล่างในกล่องเดิม เยื้องซ้าย 22 · chevron หมุนลง 90° · ไม่ใช้ hover

| State ของแถว | ค่า |
|---|---|
| default | ink · ไอคอน text-2 |
| hover / focus (คีย์บอร์ด) | พื้น muted-hover pill · ไม่มี ring แยก (แถบคือ focus) |
| active | พื้น selected |
| selected (เมนูเลือกค่า) | ✓ ท้ายแถว สี link |
| disabled | text-disabled · `aria-disabled` · โฟกัสข้ามไม่ได้ข้าม (อ่านได้) |
| danger | danger · hover พื้น danger-tint |
| has submenu · open | พื้น muted-hover ค้าง · `aria-expanded="true"` |
| loading / error / success | ไม่มีในเมนู — ผลของคำสั่งไปแสดงที่ toast หรือ dialog |

## Popover
- พื้น `--raised` · มุม 16 · padding 16 · เงา elevation-3 · กว้าง 280 · ห่างปุ่ม 8 · ไม่มีลูกศรชี้
- หัวข้อ 14/500 · คำอธิบาย 12 text-2 · ปุ่มในนั้นใช้ขนาด sm (32)
- เปิดแล้วโฟกัสไปสิ่งแรกที่กดได้ · Esc / กดนอก = ปิด แล้วโฟกัสกลับปุ่มที่เปิด · `role="dialog"` + `aria-label`

## Tooltip
- พื้นสีเดียวกับ toast (light: สีหมึก · dark: เทา selected) · ตัว 12 · padding 6/10 · **มุม 8** · กว้างสุด 240 · ห่าง 8
- **ชี้ค้าง 500ms ถึงขึ้น · โฟกัสคีย์บอร์ดขึ้นทันที** · ออกจากปุ่ม/ blur = หายทันที · Esc ปิด
- ขึ้นด้านบนเป็นค่าเริ่มต้น ชนขอบ → ด้านล่าง · ไม่มีลูกศร · ไม่มีปุ่ม/ลิงก์ในนั้น
- `role="tooltip"` + ปุ่มใช้ `aria-describedby` (หรือ `aria-label` เมื่อ tooltip คือชื่อของปุ่มไอคอน)
- มือถือ: ไม่แสดง (ปุ่มไอคอนต้องเข้าใจได้เอง หรือมี label)
- ข้อความ: คำนาม/กริยาสั้นๆ ไม่มีจุดท้าย: "ดูตัวอย่าง", "ตัวเลือกเพิ่มเติม"
