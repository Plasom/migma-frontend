## เปิดอย่างไร
- ปุ่มค้นหาในแถบบน: pill สูง 36 พื้น muted ไอคอน search + "ค้นหา" + ปุ่มลัด `⌘K` ด้านขวา (Windows แสดง `Ctrl K`) · มือถือเหลือไอคอน + คำว่า ค้นหา
- ปุ่มลัด **⌘K / Ctrl+K** ทุกหน้า (กดซ้ำ = ปิด) · ปุ่มมี `aria-keyshortcuts`

## กล่อง
- กว้าง 560 · ห่างบน 12vh (ในตัวอย่าง 48) · สูงสุด min(520, 72vh) · พื้น raised มุม 20 เงา elevation-4 · พื้นหลังมืด scrim · เปิด จาง + เลื่อน 6px 160ms
- **ช่องพิมพ์** สูง 56 ตัว 16 ไอคอน search 22 text-2 · placeholder "ค้นหาผลงาน คำสั่ง หรือหน้า" · มีข้อความ = ปุ่ม "ล้าง" ขวา · เส้นคั่นใต้ช่อง
- **หัวกลุ่ม** 12/500 text-2 (ไม่ใช้ตัวพิมพ์ใหญ่ ไม่มีเส้นคั่นระหว่างกลุ่ม) · ลำดับกลุ่ม: ผลงาน → คำสั่ง → หน้า
- **แถว** 44 (มีภาพย่อ 52) เว้นซ้ายขวา 6 · แถบที่เลือก **ทรง pill** พื้น muted-hover · ไอคอน 20 text-2 · ภาพย่อ 32 มุม 6 + บรรทัดรอง 12 text-2 ("Mobile · กำลังทำ")
- **คำที่ตรง** ตัว 500 + ขีดเส้นใต้จาง (ไม่ใช้พื้นเหลือง) · ปุ่มลัดชิดขวา 12 text-2 (กติกาเดียวกับเมนู)
- ท้ายกล่อง (เฉพาะจอคอม): ↑↓ เลื่อน · ↵ เปิด · esc ปิด ตัว 12 text-2

## เนื้อหา
| ตอน | แสดง |
|---|---|
| ยังไม่พิมพ์ | **ค้นหาล่าสุด** (สูงสุด 5 · ผลงานมีภาพย่อ คำค้นมีไอคอน history) + ปุ่ม ✕ ลบทีละอัน (โผล่ตอนชี้/เลือก · จอสัมผัสโผล่ตลอด) + "ล้างทั้งหมด" ที่หัวกลุ่ม · ตามด้วย **คำสั่งแนะนำ 3 อัน** |
| พิมพ์แล้ว | กรองทุกกลุ่ม · กลุ่มละไม่เกิน 5 · เกิน = แถว "ดูผลงานทั้งหมด N รายการ" · กลุ่มที่ไม่มีผลไม่แสดงหัว |
| กำลังค้น (เกิน 300ms) | ผลเดิมค้างไว้ + วงหมุน 16 ในช่องพิมพ์ ไม่ใช้ skeleton |
| ไม่พบ | empty state ขนาดเล็ก "ไม่พบ “คำ”" + "ลองคำอื่น หรือดูผลงานทั้งหมด" |

- เลือกผลงาน/หน้า → ปิดกล่อง ไปหน้านั้น · บันทึกเข้าค้นหาล่าสุด (เก็บในเครื่องผู้ใช้) · เลือกคำค้นล่าสุด → ใส่ในช่องแล้วค้นต่อ · คำสั่ง → ทำแล้วปิด ผลขึ้น toast
- ค้นหาล่าสุดเป็นของคนนั้นคนเดียว ไม่แสดงในเครื่องอื่น

## คีย์บอร์ดและการเข้าถึง
- โฟกัสอยู่ที่ช่องพิมพ์ตลอด: `role="combobox"` + `aria-controls` → `role="listbox"` · แถว `role="option"` · แถวที่เลือก `aria-selected` + `aria-activedescendant`
- ↑↓ เลื่อน (วน) · Home/End ไปบนสุด/ล่างสุด (เมื่อช่องว่าง) · Enter เปิด · **Esc: มีข้อความ = ล้าง · ว่าง = ปิด** · ⌘⌫ / Shift+Delete ลบคำค้นล่าสุดที่เลือกอยู่ · Tab ไม่ออกจากกล่อง
- ชี้เมาส์ = เปลี่ยนแถวที่เลือก · ปิดแล้วโฟกัสกลับที่เดิม

## มือถือ (≤ 600)
- เต็มจอแบบ M3 search view: ลูกศรย้อนกลับซ้าย (แทนไอคอน search) + ช่องพิมพ์ + "ล้าง" · ไม่มีปุ่มลัด ไม่มีท้ายกล่อง · แถวสูงเท่าเดิม (≥ 44)
