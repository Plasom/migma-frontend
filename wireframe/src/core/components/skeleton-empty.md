## Skeleton
- แท่งข้อความหลัก `--skel-fill` (= muted) · ภาพ/ข้อความรอง `--skel-fill-soft` (muted 55%) · แท่งสูง 12 (รอง 10) มุม 6 ห่างกัน 8
- **รูปทรงตรงกับของจริง**: การ์ดผลงานใช้ padding, มุม, อัตราส่วนภาพ 16:10, ตำแหน่งแท็กเดียวกับ card v1.2 · avatar เป็นวงกลมขนาดจริง · ความกว้างแท่งไม่เท่ากัน (ประมาณ 40–90%) ให้ดูเหมือนข้อความ
- **ไม่ขยับ** ไม่กะพริบ ไม่มีแสงวิ่ง · เนื้อหาจริงจางเข้า `--skel-reveal` (240ms) · `prefers-reduced-motion` = ขึ้นทันที
- **แสดงเมื่อรอเกิน `--skel-delay` 300ms** (เร็วกว่านั้นให้เนื้อหาขึ้นเลย) · แสดงแล้วค้างอย่างน้อย `--skel-min-show` 400ms กันกะพริบ
- จำนวน: เท่าที่คาดว่าจะมา และไม่เกินที่เห็นในจอแรก (การ์ด ≤ 6, แถว ≤ 5, ย่อหน้า ≤ 3 บรรทัด) · มือถือแสดงการ์ด 1 ใบ
- ไม่ใส่ skeleton ให้ปุ่ม ชื่อหน้า และเมนู (ของพวกนี้ขึ้นทันที) · ภาพที่ยังโหลดอยู่ในการ์ดที่โหลดเสร็จแล้วใช้พื้น `--skel-fill-soft` เดียวกัน
- การเข้าถึง: กล่องที่โหลด `aria-busy="true"` + ข้อความซ่อน "กำลังโหลด…" · แท่ง skeleton `aria-hidden="true"` · เสร็จแล้ว `aria-busy="false"`

## Empty state
- กลางพื้นที่ กว้างสุด 360 · padding 48/24 (มือถือ 40/16) · หัวข้อ 22/500 (มือถือ 20) สี ink · คำอธิบาย 14 text-2 1 บรรทัด · ปุ่มห่างคำอธิบาย 20
- **ไม่มีไอคอนใหญ่ ไม่มีภาพประกอบ ไม่มีกรอบเส้นประ** (กรอบเส้นประใช้เฉพาะช่องลากไฟล์มาวาง)
- ปุ่ม **ไม่เกิน 1 ปุ่ม** และต้องแก้ปัญหาได้จริง · ไม่มีอะไรให้ทำ = ไม่มีปุ่ม

| กรณี | หัวข้อ | ปุ่ม |
|---|---|---|
| ครั้งแรก ยังไม่มีข้อมูล | ชวนเริ่ม "เริ่มเพิ่มผลงานชิ้นแรก" | filled (ปุ่มหลักของหน้า) |
| ค้นหา/กรองแล้วไม่เจอ | "ไม่พบ “คำที่ค้น”" + บอกจำนวนตัวกรอง | outlined "ล้างตัวกรอง" |
| ทำครบแล้ว | บอกผล "ตอบครบทุกข้อความแล้ว" | ไม่มี |
| โหลดไม่สำเร็จ | "โหลด…ไม่ได้" + วิธีแก้ · `role="alert"` | outlined "ลองอีกครั้ง" |
| ขนาดเล็ก (ในเมนู แผงข้าง การ์ด) | 15/500 · คำอธิบาย 13 · padding 24/16 | text sm |

### ข้อความ (ภาษาไทย)
- หัวข้อเป็นคำชวนทำหรือบอกสถานะ ไม่ขอโทษ ไม่ใช้ "ไม่มีข้อมูล" "ว่างเปล่า" "อุ๊ย!"
- คำอธิบายบอกว่าจะได้อะไร/ทำอะไรต่อ 1 ประโยค ไม่มีจุดท้าย ไม่มีอีโมจิ
- ปุ่มขึ้นต้นด้วยกริยา 1–3 คำ ("เพิ่มผลงาน" "ล้างตัวกรอง")
