# Select — v1 (2026-10-11)

ตัวเลือกแบบเลือก 1 ค่า ประกอบจากคอมโพเนนต์เดิมของระบบ ไม่ใช้ `<select>` ของเบราว์เซอร์ (หน้าตาต่างกันทุกเครื่อง · ค้นหาไม่ได้) · ใช้ครั้งแรกในหลังบ้าน (`preview/editor.html` · decisions #103)

## ส่วนประกอบ
| ส่วน | มาจาก | รายละเอียด |
|---|---|---|
| ทริกเกอร์ | Input · Soft fill | สูง `--input-h-md` · ข้อความค่าปัจจุบัน (ยังไม่เลือก = สี placeholder) · ไอคอน `expand_more` ขวา · เปิดอยู่ = พื้น `--input-bg-focus` + วง `--input-ring` |
| ทริกเกอร์แบบเรียง | Button ghost sm | “เรียง: ใหม่สุดก่อน ▾” สี `--text-2` · ใช้หัวรายการ |
| แผง | Menu | `--menu-bg` `--menu-radius` `--menu-shadow` · กว้าง = ทริกเกอร์ (อย่างน้อย 260) · สูงสุด 360 · ที่ด้านล่างไม่พอ = พลิกขึ้น · อยู่ในจอเสมอ |
| ช่องค้นหา | Command palette input | เปิดเมื่อตัวเลือก > 6 หรือข้อมูลเยอะ · ทรง pill · ตัวที่ตรงเป็นตัวหนา · ไม่เจอ = “ไม่พบ “…” · ลองคำอื่น” |
| ตัวเลือก | Menu item | สูง `--menu-item-h` · ค่าที่เลือก = ✓ `--link` ท้ายแถว + `aria-selected` · มีบรรทัดรองได้ (`--caption`) |
| หัวกลุ่ม | Menu section label | `--caption` `--text-2` |

## ลงลึก 2 ชั้น (เช่น ผลงาน → Case study)
- ชั้นแรก: กลุ่ม (ชื่อ + จำนวน + `chevron_right`) · กด / → = เข้าไป
- ชั้นสอง: แถว “← ผลงานทั้งหมด” บนสุด + หัวกลุ่ม + ตัวเลือก · Esc / ← = ย้อนชั้น
- พิมพ์ค้นหา = แบนทุกกลุ่ม ค้นทั้งชื่อตัวเลือกและชื่อกลุ่ม (ชื่อกลุ่มเป็นบรรทัดรอง)

## คีย์บอร์ด
↓/↑ บนทริกเกอร์ = เปิด · ↓/↑ ในแผง = เลื่อน (จากช่องค้นหาลงไปตัวเลือกได้) · Enter = เลือก (ในช่องค้นหา = เลือกตัวแรก) · Esc = ปิด/ย้อนชั้น โฟกัสกลับทริกเกอร์ · Tab = ปิด · เลือกแล้วโฟกัสกลับทริกเกอร์

## ห้าม
- ใช้ Select กับตัวเลือก ≤ 3 ที่ต้องเห็นพร้อมกัน → ใช้ Radio หรือ Segmented
- ใช้ `<select>` ของเบราว์เซอร์ในหน้าใหม่
