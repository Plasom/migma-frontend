# Dialog — v1 (2026-10-10)

แบบ **Spotify ปรับแล้ว** · กลางจอทั้งเดสก์ท็อปและมือถือ · ปุ่ม pill เรียงข้างกัน
ตัวอย่าง: `preview/components.html` § Dialog · token: `core/tokens-core.css` § Dialog

## ใช้เมื่อไหร่
- **เฉพาะเรื่องที่ย้อนกลับไม่ได้** หรือต้องตัดสินใจก่อนไปต่อ: ลบถาวร, ส่งแล้วแก้ไม่ได้, ออกโดยงานที่ยังไม่บันทึกจะหาย
- อะไรที่ย้อนกลับได้ (ย้ายไปถังขยะ, ซ่อน, เก็บถาวร) **ไม่ถาม** → ทำทันที + toast "เลิกทำ" (toast.md)
- ฟอร์มยาว / เลือกจากรายการ ไม่ใช้ dialog นี้ (รอ Sheet)

## หน้าตา
- กว้างสุด 400 · มุม 16 · padding 24 (มือถือ 20) · พื้น surface · เงา elevation-3 · พื้นหลังมืด `--scrim`
- มือถือ: กลางจอ เว้นขอบซ้ายขวา 16 (ไม่ใช่แผ่นจากด้านล่าง — แผ่นล่างเก็บไว้ใช้กับ "เลือกจากรายการ")
- **หัวข้อ** 17/500 บอกการกระทำ + ชื่อสิ่งที่โดน (ตัวหนา): "ลบ **แอปธนาคาร** ถาวร" · ไม่ใช้คำถามแม่แบบ "คุณแน่ใจหรือไม่?"
- **เนื้อหา** 14 text-2 บอกผลที่ตามมาเป็นข้อเท็จจริง: "ภาพ ข้อความ และลิงก์ทั้งหมดของงานนี้จะหายไป กู้คืนไม่ได้"
- ไม่มีไอคอนในกล่องเหนือหัวข้อ (Hallmark) · ไม่มีปุ่ม ✕ (มีปุ่มยกเลิกแล้ว)

## ปุ่ม
- pill สูง 40 (มือถือ 44) ห่างกัน 8 · ชิดขวา · **ยกเลิกซ้าย ยืนยันขวา** ทั้งเดสก์ท็อปและมือถือ
- มือถือ: สองปุ่มแบ่งความกว้างเท่ากัน · ถ้าข้อความปุ่มยาวจนไม่พอ → ซ้อนลงเป็นแถว (ยืนยันบน ยกเลิกล่าง) อัตโนมัติ
- ยกเลิก = พื้น `--muted` ตัว ink · ยืนยันอันตราย = danger filled · ยืนยันทั่วไป = primary filled
- คำบนปุ่มเป็นกริยา + สิ่งที่ทำ: "ลบถาวร", "ส่งข้อความ", "ออกโดยไม่บันทึก" · ห้าม "ตกลง" / "ใช่"

## พฤติกรรม
- เข้า 240ms ease-emphasized (ขยายจาก 96% + จาง) · ออก 160ms · reduced-motion = จางอย่างเดียว
- โฟกัสแรก: **ปุ่มยกเลิก** เมื่อเป็นเรื่องอันตราย (กด Enter ทันทีจะไม่ลบ) · ปุ่มยืนยันเมื่อเป็นเรื่องทั่วไป
- Tab วนอยู่ใน dialog · Esc / กดพื้นมืด = ยกเลิก · ปิดแล้วโฟกัสกลับไปปุ่มที่เปิด · ล็อกการเลื่อนหน้า
- `role="alertdialog"` (อันตราย) หรือ `role="dialog"` · `aria-modal="true"` · `aria-labelledby` หัวข้อ · `aria-describedby` เนื้อหา

| State | ค่า |
|---|---|
| ปุ่ม hover / focus / active | ตาม button.md |
| loading (ยืนยันแล้วรอเซิร์ฟเวอร์) | ปุ่มยืนยันเป็น spinner + "กำลังลบ" · ปุ่มยกเลิกปิด · Esc ปิดไม่ได้ |
| error | **ไม่แสดงใน dialog** · dialog ปิด แล้วขึ้น toast ผิดพลาด "ลบ แอปธนาคาร ไม่ได้ · ตรวจการเชื่อมต่อแล้วลองอีกครั้ง" + ปุ่ม "ลองอีกครั้ง" (ทำคำสั่งเดิมซ้ำ ไม่ต้องเปิด dialog ใหม่) |
| success | dialog ปิด + toast ผลลัพธ์ |
| disabled | ปุ่มยืนยันปิดได้เฉพาะเมื่อมีเงื่อนไข (เช่น ต้องพิมพ์ชื่องานก่อนลบ) |
