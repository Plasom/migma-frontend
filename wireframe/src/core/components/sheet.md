## แผ่นล่าง (มือถือ)
- พื้น `--raised` · มุมบน 20 · เงา elevation-4 · พื้นหลังมืด `--scrim` · สูงสุด 90dvh (เนื้อหายาวเลื่อนในแผ่น หัวและท้ายอยู่กับที่) · เว้น safe-area ด้านล่าง
- **ขีดจับ** 36×5 ทรง pill สี border-control ห่างขอบบน 6 · ลากขีดจับหรือส่วนหัวลง > 30% ของความสูง หรือปัดเร็ว = ปิด · ไม่ถึงก็เด้งกลับ
- **ส่วนหัวเป็นชิ้นงาน**: ภาพย่อ 40 มุม 8 + ชื่องาน 15/500 + บรรทัดรอง 13 text-2 (บอกว่ากำลังทำอะไร เช่น "ย้ายไปโฟลเดอร์") · เส้นคั่นใต้หัว · แผ่นที่ไม่ได้เกี่ยวกับชิ้นงานใด ใช้ชื่อแผ่นอย่างเดียว ไม่มีภาพย่อ
- **แถว** สูง 48 เว้นซ้ายขวา 8 · ไอคอน 22 text-2 · ตัว 15 · แถบ hover/กด ทรง pill (muted-hover / selected) เหมือนเมนู
- ตัวที่เลือกอยู่: ตัว + ไอคอนสีแบรนด์ (link) 500 + ✓ ท้ายแถว · คำสั่งอันตรายอยู่ล่างสุดแยกกลุ่ม สีแดง
- ปุ่ม **"ปิด"** ล่างสุด กลาง 48 (แตะพื้นมืด / Esc / ลากลง ก็ปิดได้)
- เปิด 320ms ease-enter · ปิด 220ms · พื้นมืดจางตาม

### 3 แบบ
| แบบ | การทำงาน | ท้ายแผ่น |
|---|---|---|
| คำสั่ง | แตะ = ทำแล้วปิด · คำสั่งที่ย้อนได้ (ลบไปถังขยะ ซ่อน) ขึ้น toast + เลิกทำ · คำสั่งที่เปิดรายการต่อ (ย้ายไปโฟลเดอร์) ปิดแผ่นนี้แล้วเปิดแผ่นใหม่ ไม่ซ้อน | ปิด |
| เลือกแล้วทำทันที | แตะ = เปลี่ยนค่า ปิดแผ่น toast + เลิกทำ · `role="radiogroup"` / `role="radio"` | ปิด |
| **เลือกแล้วกดบันทึก** | ใช้เมื่อ **เลือกได้หลายอัน** หรือเปลี่ยนแล้วมีผลกับคนอื่น (สิทธิ์การเห็น) · แถวมี checkbox ขวา (ทรง Fastwork) แตะ = สลับ ยังไม่บันทึก · `role="checkbox"` | ปุ่ม filled เต็มความกว้าง 48 "บันทึก (จำนวน)" + "ยกเลิก" ใต้ปุ่ม · ปิดโดยไม่กดบันทึก = ทิ้งที่เลือกไว้ ไม่ต้องถามยืนยัน · บันทึกแล้ว toast |

## แผ่นด้านขวา (จอคอม)
- กว้าง 400 (จอแคบ = เต็มความกว้าง) · สูงเต็มจอ · มุมซ้าย 20 · ไม่มีขีดจับ
- หัว: ชื่อ 17/500 + ปุ่มไอคอน ✕ ขวา · เนื้อหาเลื่อนได้ padding 24 · ท้าย: ปุ่มรองซ้าย (text "ล้างทั้งหมด") ปุ่มหลักขวา (filled)
- ตัวกรองใช้ filter chip · เปลี่ยนแล้วยังไม่กรองจนกดปุ่มหลัก (เมื่อการกรองช้า) หรือกรองทันทีแล้วปุ่มหลักแค่ปิด (เมื่อเร็ว) — เลือกแบบเดียวต่อหนึ่งหน้า
- เปิดเลื่อนจากขวา 320ms · ปิด 220ms

## การเข้าถึง
- `role="dialog"` + `aria-modal="true"` + `aria-labelledby` ชี้ชื่อในหัว · ปุ่มที่เปิด `aria-haspopup="dialog"`
- เปิดแล้วโฟกัสไปตัวที่เลือกอยู่ (หรือแถวแรก) · Tab วนอยู่ในแผ่น · ↑↓ เลื่อนระหว่างแถว · Esc ปิด · ปิดแล้วโฟกัสกลับปุ่มที่เปิด
- ลากเพื่อปิดเป็นทางเสริม ต้องมีปุ่ม "ปิด"/"ยกเลิก"/✕ เสมอ
- `prefers-reduced-motion`: จางเข้า-ออกแทนการเลื่อน

| State ของแถว | ค่า |
|---|---|
| default | ink · ไอคอน text-2 |
| hover | พื้น muted-hover pill |
| pressed | พื้น selected |
| focus (คีย์บอร์ด) | ring 2px input-ring ด้านใน |
| เลือกอยู่ | link 500 + ✓ (แบบ radio) · checkbox เต็มสีแบรนด์ (แบบหลายอัน) |
| disabled | text-disabled · `aria-disabled` · ไอคอนกุญแจ + เหตุผลในชื่อ |
| danger | danger · hover พื้น danger-tint |
| loading / error / success | ไม่อยู่ในแถว — บันทึกแล้วปิดแผ่น ผลขึ้นที่ toast · บันทึกไม่ได้ = แผ่นไม่ปิด + toast ผิดพลาด |
