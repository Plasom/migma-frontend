## 1. Status label (แทน badge)
- ตัวอักษร `12/500` line-height 1.5 · ไม่มีพื้น ไม่มีกรอบ ไม่มีจุด
- **มีสีแค่ "กำลังทำ"** = `--warning-strong` (B26222 · 4.5:1 / dark F0A35E · 7.7:1) · ที่เหลือ `--text-2`
- ไอคอนนำหน้าได้เฉพาะ `lock` (13px, FILL 1) ของ "ติด NDA"
- วาง**เหนือชื่องาน ห่าง 2px** อ่านต่อกันเป็นประโยคเดียว

### คำที่ใช้ใน portfolio มีแค่ 3 คำ
| คำ | สี | บรรทัด meta ด้านล่างบอกอะไร |
|---|---|---|
| กำลังทำ | warning-strong | "คาดว่าเสร็จ ธ.ค. 2026" |
| โปรเจกต์ส่วนตัว | text-2 | ปี |
| 🔒 ติด NDA | text-2 + ไอคอน lock | "ขอดูได้ทางอีเมล" |

งานที่เสร็จและขึ้นจริงแล้ว = **ไม่มี status label** (เป็นเรื่องปกติ) · งานนอก portfolio (ตาราง, dashboard) ที่สถานะเป็นข้อมูลหลัก ใช้แบบมีพื้นสีอ่อน `--*-tint` + จุดได้ — ดู §6

## 2. Tag
- สูง 22 · padding 0 9 · มุม full · ตัว `12/400`
- พื้น `--tag-bg` (ECEEF2) · ตัวอักษร `--tag-fg` (text-2 · 4.8:1)
- **ทุกสีเป็นเทา** ห้ามแยกสีตามหมวด
- ไม่เกิน **3 อันต่อการ์ด** · ระยะห่างกัน 6
- เป็น `<a href="/work?tag=mobile">` → กดแล้วไปหน้ารายการที่กรองไว้ (ตรงกับ filter chip)
- tag ที่กดไม่ได้ (เช่นในหน้า case study) ใช้หน้าตาเดียวกันแต่ไม่มี hover

| State | ค่า |
|---|---|
| default | bg ECEEF2 · fg 636875 |
| hover | bg E4E7EC · fg ink |
| focus-visible | ring 2px primary offset 2 (แสดงทันที ไม่ animate) |
| active | bg DADEE5 |
| disabled / loading / error / success | ไม่มี — tag เป็นลิงก์ ไม่มีสถานะเหล่านี้ |

## 3. Filter chip
- สูง 32 (เล็ก 28 ใช้ในเครื่องมือ compact) · padding 0 14 · มุม full · ตัว `13/500`
- **ไม่มีกรอบ ไม่มีพื้น** ตอนยังไม่เลือก · เลือกแล้ว = พื้นทึบสีหมึก (ไม่ใช่สี primary — ไม่แย่งความเด่นกับปุ่มหลัก)
- ไม่มีไอคอน ✓ (พื้นทึบบอกพอแล้ว)
- `<button aria-pressed>` อยู่ใน `role="group" aria-label="กรองตามประเภท"`
- มือถือ: แถว chip เลื่อนแนวนอนได้ (`overflow-x:auto; scroll-snap`) · พื้นที่กดขยายเป็น 44 ด้วย `::before` inset -6px

| State | ไม่เลือก | เลือกแล้ว |
|---|---|---|
| default | fg 636875 | bg 23262E · fg FFF |
| hover | fg ink + bg gray-50 | bg 3A3D47 |
| focus-visible | ring 2px primary offset 2 | เหมือนกัน |
| active | bg ECEEF2 | bg 15171C |
| disabled (หมวดนี้ไม่มีงาน) | fg 8A90A0 · `aria-disabled` + title บอกเหตุผล | — |
| loading | chip เปลี่ยนเป็นเลือกทันที (optimistic) · รายการด้านล่าง `aria-busy` + skeleton | |
| error | chip คงสถานะ · ข้อความในพื้นที่รายการ "โหลดรายการไม่ได้ ลองอีกครั้ง" + ปุ่ม | |
| success | เงียบ (รายการเปลี่ยนเอง) · ประกาศจำนวนผ่าน `aria-live="polite"` "แสดง 4 งาน" | |

## 4. Input chip
- สูง 30 · padding 0 4 0 13 · มุม full · ตัว `13/500` สี ink · พื้น `--tag-bg`
- ปุ่ม ✕ ขนาด 20 กลม · ไอคอน `close` 14 · `aria-label="เอา Figma ออก"`
- ใช้ใน: แถว "เลือกไว้" เหนือรายการ, ช่องกรอกแบบ tags (`input.md`) — **ในช่องกรอก (พื้น ECEEF2) chip ใช้พื้น surface** ไม่งั้นมองไม่เห็น
- ท้ายแถวมีลิงก์ "ล้างทั้งหมด" (สี link)
- Backspace ในช่องว่าง = ลบ chip ตัวสุดท้าย

| State | ค่า |
|---|---|
| default | bg ECEEF2 · ✕ สี text-2 |
| hover (ที่ ✕) | ✕ bg rgba(35,38,46,.08) · สี ink |
| focus-visible (ที่ ✕) | ring 2px primary |
| active (ที่ ✕) | ✕ bg rgba(35,38,46,.14) |
| disabled | bg gray-50 · fg 8A90A0 · ไม่มี ✕ |
| loading | (เช่นกำลังตรวจอีเมลที่พิมพ์) ตัวอักษร text-2 + spinner 12 แทน ✕ |
| error | bg danger-tint · fg danger-tint-fg · `aria-invalid` + ข้อความใต้ช่อง "อีเมลนี้ไม่ถูกต้อง" |
| success | เงียบ · chip กลับเป็น default |

## 5. Count
- **ค่าเริ่มต้น = จุด** 10px สี `--danger` + ขอบ 2px สีพื้นหลัง · มุมขวาบนของไอคอน (top/right -1)
- ใช้ตัวเลขเฉพาะเมื่อจำนวนมีความหมาย (ข้อความที่ยังไม่อ่าน) · สูง 18 · min-w 18 · padding 0 5 · `11/500` tabular-nums · เกิน 99 แสดง "99+"
- ตัวเลขโหมดมืดใช้ตัวอักษรเข้ม 16181D บน F27380 (ขาวได้แค่ 2.8:1)
- จำนวนอยู่ใน `aria-label` ของปุ่ม: `aria-label="แจ้งเตือน 3 รายการ"` · จุด/ตัวเลข `aria-hidden`
- **ไม่กะพริบ ไม่ ping**

## 6. นอก portfolio — Status แบบมีพื้น
ใช้เมื่อสถานะเป็นข้อมูลหลักที่ต้องกวาดตา (คอลัมน์ในตาราง, รายการงาน, dashboard)
สูง 22 · padding 0 10 0 8 · มุม full · `12/500` · พื้น `--success-tint` / `--warning-tint` / `--danger-tint` / `--primary-tint` · จุด 6px สี status · ตัวอักษร `--*-tint-foreground`
ยังต้องเป็นภาษาเดียวทั้งชุด และหนึ่งแถวมีได้อันเดียว

## กติกาป้าย (จาก Hallmark · 2026-10-10)
1. **ไม่ติดป้ายทุกใบ** — ป้ายบอกสิ่งที่ต่างจากปกติเท่านั้น
2. **เขียนข้อเท็จจริง ไม่ใช่คำลอยๆ** — "New", "Live", "Featured", "Hot" ไม่บอกอะไร → "ใช้งานจริง มี.ค. 2026" ในบรรทัด meta
3. **หมวดหมู่เป็น tag เทา ไม่ใช่ pill หลายสี**
4. **สีมีไว้สำหรับสถานะที่ต้องสังเกตเท่านั้น**
5. **ไม่วางป้ายบนรูป** (ต้องเติมพื้นกระจก/เงาเพื่อให้อ่านออก)
6. **ไม่กะพริบ ไม่ใส่ emoji ไม่ไล่สี** — จุดเขียวกะพริบ + "Available for work" คือป้าย AI ที่เจอบ่อยที่สุด · "ว่างรับงาน" เขียนเป็นข้อความธรรมดา "รับงานใหม่ได้ตั้งแต่ [เดือน]"
7. **การ์ดหนึ่งใบ = status ได้อันเดียว**
8. **ไม่ใช้ตัวพิมพ์ใหญ่ทั้งคำ ไม่ถ่างตัวอักษร** — ไทยทำไม่ได้ ป้ายสองภาษาจะไม่เข้าชุด · ใช้ภาษาเดียวทั้งชุด
