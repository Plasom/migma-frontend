## Modifiers
| Modifier | ค่า |
|---|---|
| `.click` | hover: ลอย 3px + elevation 2 (240ms ease-standard) · focus ring ทั้งใบ |
| `.flat` | ไม่มีเงา · เส้นขอบ border E4E7EC |
| `row` | flex แนวนอน · thumbnail 64–72 จัตุรัส · padding 16 |
| `selectable` | เส้นขอบ 1.5px border → hover 8A90A0 → selected primary + พื้น primary 5% + radio |
| `empty` | เส้นประ 1.5px · ไม่มีพื้น · ข้อความกลาง |
| `skeleton` | shimmer muted ↔ sunken 1.4s · `aria-busy="true"` |

## กฎจาก Hallmark audit (2026-10-10)
1. **Mesh 1 จุดต่อหน้า** — Featured ใบเดียว + เกรน · ที่เหลือใช้ Indigo mist / sunken / ภาพจริง
2. **ห้ามวาดหน้าจอปลอม** (กรอบมือถือ, browser bar) — ใส่ภาพหน้าจอจริงใน `<figure>` · ระหว่างยังไม่มีภาพใช้ช่องเส้นประ `.ph` บอกอัตราส่วน เช่น "ภาพผลงานจริง 16:10"
3. **ห้ามแต่งตัวเลข / รีวิว** — ใช้ `— รอตัวเลขจริง` จนกว่าจะมีข้อมูลจริง · รีวิวต้องขออนุญาตเจ้าของคำพูด
4. **ไอคอนไม่อยู่ในกล่องสีเหนือหัวข้อ** — วางบรรทัดเดียวกับหัวข้อ (สี link) หรือไม่ใช้
5. **ตัวเลขใช้ tabular-nums** (ราคา, สถิติ, เวลา)
6. **ชื่อการ์ดตัด 2 บรรทัด** (`-webkit-line-clamp: 2`)
7. **การ์ดกดได้ = `<a>` หรือ stretched link** + focus ring ทั้งใบ · ปุ่มด้านในอยู่เหนือ link (`z-index: 1`)
8. **สีถูกใจ = `--like` (primary)** ไม่ใช้สี danger
9. **Featured ใช้กริด 2 คอลัมน์** (ข้อความ 1fr · ภาพ .42fr) ภาพอยู่ใน padding เดียวกัน — ห้ามวางภาพลอย (absolute) จนล้นขอบ · มือถือภาพลงไปอยู่ใต้ข้อความ 16:10
10. **CTA ต้องบอกสิ่งที่จะเกิดขึ้นจริง** — ห้ามไอคอนคลิเช่ (🚀 จรวด, ✨ ประกาย), ห้ามหัวข้อคำถามกว้างๆ ("พร้อมเริ่มโปรเจกต์ใหม่ไหม"), ห้ามพื้นไล่สี · ใช้การ์ด flat + สถานะจริง (ว่างรับงานเมื่อไหร่) + ช่องทางจริง (อีเมลพร้อมปุ่มคัดลอก) + ปุ่ม 1 หลัก 1 รอง
11. ค่าสีทุกค่าเป็น token (`--on-media`, `--scrim-media`, `--glass`, `--ph-border`, `--avatar-alt`, `--rating`)
12. **ป้ายบนการ์ด** — ไม่ติดทุกใบ · ไม่ใช้คำลอยๆ ("New", "Featured", "Live") · หมวดหมู่เป็น tag เทา · ไม่วางบนรูป · ไม่กะพริบ (รายละเอียด `chip.md`)

## Project layout (v1.2)
```
┌ การ์ด มุม 20 · padding 10 ─────────┐
│ [ภาพ 16:10 มุม 10]                  │
│   ↕ 12                              │
│   กำลังทำ          ← status label (เฉพาะงานที่ต่างจากปกติ) │
│   ↕ 2                               │
│   ระบบจองคิวคลินิก  ← title-md ตัด 2 บรรทัด · เป็น stretched link │
│   ↕ 10                              │
│   (Web) (UI) (Usability test) ← tag ≤ 3 เป็นลิงก์ไปหน้ากรอง (z-index 1) │
│   ↕ 8                               │
│   คาดว่าเสร็จ ธ.ค. 2026 ← meta 12 text-2 │
└──── padding ล่าง 14 ────────────────┘
```
- ระยะ 3 ระดับ: **2** ในกลุ่มเดียวกัน · **8–10** ระหว่างกลุ่ม · **12** ระหว่างภาพกับเนื้อหา
- ข้อความเยื้องเข้ามากกว่าภาพ 4px เพื่อไม่ให้ชิดมุมโค้ง
- เพราะ tag เป็นลิงก์ การ์ดจึง**ห้ามเป็น `<a>` ทั้งใบ** (ลิงก์ซ้อนลิงก์) → ใช้ชื่องานเป็น `a.stretch` (`::after inset:0`) + focus ring ที่การ์ดด้วย `:has(.stretch:focus-visible)`
- ไม่มีคำอธิบายในการ์ด Project (อยู่ใน case study) · ถ้าจำเป็นใส่ได้ 1 บรรทัดระหว่างชื่อกับ tag ห่าง 4
- การ์ดที่มี status ชื่องานจะต่ำกว่าใบข้างๆ ~18px — ยอมรับได้เพราะ status มีเฉพาะบางใบ
- กติกา status/tag ทั้งหมด: `chip.md`

## Hover ตามแบบ
Project / Commerce / Info(กดได้) = ลอย 3px + เงา (active ลอย 1px) · Featured = ภาพด้านในขยับขึ้น 6px · Shot = overlay อย่างเดียว · Shelf = พื้นเข้มขึ้น + ปุ่มลูกศรเลื่อนขึ้น · **1 สัญญาณต่อแบบ**
