## โครง (เดสก์ท็อป ≥ 720px)
```
┌──────────────────────────── 48px · sticky · พื้นโปร่ง 80% + blur 16 · เส้นล่าง 1px ───┐
│ ●●●● phunyisa                                          หน้าแรก  ผลงาน  ประวัติ  ติดต่อ [◐]│
└───────────────────────────────────────────────────────────────────────────────────────┘
  โลโก้ชิดซ้าย                                 ลิงก์ชิดขวาคู่ปุ่มไอคอน (grid 1fr auto auto · ห่าง 16)
```
- สูง 48 · ขอบซ้ายขวา 24 (มือถือ 16) · ลิงก์ห่างกัน 28 · ตัวอักษร 14/400 (Apple ใช้ 12 แต่ภาษาไทยเล็กไปจะอ่านยาก)
- ลิงก์ **4** (หน้าแรก · ผลงาน · ประวัติ · ติดต่อ) ไม่เกิน 4 · "หน้าแรก" เป็นลิงก์ที่เห็นชัด ไม่พึ่งโลโก้อย่างเดียว (decisions #98) · ส่วนวิธีทำงานและ Case study นับเป็น "ผลงาน" ตอนเลื่อนผ่าน · ตอนอยู่ hero = "หน้าแรก" · ชื่อสั้น 1–2 คำ · ภาษาไทยเป็นหลัก (คำเฉพาะเช่น "Case study" ใช้อังกฤษได้)
- ขวามีได้แค่**ปุ่มไอคอน** (โหมดมืด, ค้นหา) ขนาด 36 แบบ ghost · ห้ามปุ่ม filled/outline เช่น "Contact", "Hire me"
- **เส้นล่าง**: โปร่งใสตอนอยู่บนสุด ขึ้นเมื่อเลื่อนเกิน 4px (160ms) · ตอนบนสุดแถบกลืนกับหน้า
- พื้น `--nav-bg` (background 80%) + `backdrop-filter: blur(16px)` · ถ้าเบราว์เซอร์ไม่รองรับ blur ใช้พื้นทึบ

## หน้าที่อยู่ (current)
- สีตัวอักษร ink + น้ำหนัก 500 (ลิงก์อื่น text-2 / 400) · `aria-current="page"` (หรือ `"location"` ในหน้าเดียวเลื่อน)
- กันตัวหนังสือขยับตอนเปลี่ยนน้ำหนัก: จองความกว้างด้วย `::after { content: attr(data-label); font-weight: 500; visibility: hidden; height: 0 }`
- หน้าเดียวเลื่อน (landing): เปลี่ยนตาม section ที่อยู่บนจอ (IntersectionObserver) · ไม่มีเส้นใต้ ไม่มีจุด ไม่มีพื้น

## State ของลิงก์
| State | ค่า |
|---|---|
| default | `--nav-link` (text-2) |
| hover | `--nav-link-hover` (ink) · 120ms |
| focus-visible | ring 2px `--focus-ring` offset 4 มุม 6 · แสดงทันที |
| active (กด) | ink ทันที |
| current | ink + 500 |
| disabled / loading / error / success | ไม่มี — nav ไม่ปิดลิงก์ ถ้าหน้ายังไม่พร้อมให้เอาลิงก์ออก |

## มือถือ (< 480px) — แผ่นเลื่อนจากขวาแบบ shadcn Sheet
- 480–719px ลิงก์ยังอยู่ในแถบ ห่าง 20 · ต่ำกว่า 480 ลิงก์หาย · ขวามีปุ่ม `menu` (36, `aria-expanded`, `aria-controls`) ข้างปุ่มโหมดมืด
- กดแล้ว**แผ่นเลื่อนจากขวา** กว้าง `min(320px, 85vw)` สูงเต็มจอ · เส้นซ้าย 1px + เงา elevation-4 · พื้นหลังมืด `--scrim` (กดพื้นมืดเพื่อปิด)
- เข้า 300ms `ease-emphasized` · ออก 300ms `ease-standard` · reduced-motion = จางเข้า/ออก 100ms
- หัวแผ่น: โลโก้ซ้าย + ปุ่ม `close` ขวา (สูงเท่าแถบ 48)
- ลิงก์ 18/500 แถวสูง 48 · แถบ hover/เลือก**ทรง pill** (มนสุด แบบ M3 drawer) เว้นซ้ายขวา 16 ให้ตัวหนังสือตรงกับโลโก้ · ปกติ text-2 · hover พื้น ghost · **หน้าที่อยู่ = ตัว ink + พื้น muted** (บนมือถือไม่มี hover จึงต้องมีพื้นให้เห็น)
- ปุ่มรอง "Resume (PDF)" เต็มความกว้าง ชิดล่างสุดของแผ่น
- เป็น `role="dialog" aria-modal="true"` · โฟกัสไปลิงก์แรกเมื่อเปิด · Tab วนอยู่ในแผ่น · Esc / ปุ่มปิด / กดพื้นมืด / กดลิงก์ = ปิด แล้วโฟกัสกลับปุ่มเมนู · ล็อกการเลื่อนหน้าระหว่างเปิด
