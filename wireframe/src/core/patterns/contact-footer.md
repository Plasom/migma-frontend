## พื้นส่วนท้าย (หน้าแรก)
- ส่วนติดต่อ + footer อยู่บน**พื้นสีอ่อนเต็มความกว้างจอ** `--sidebar` (light #F2F3F6 · dark #1B1D23) เป็นก้อนตอนจบก้อนเดียว · ห่างเนื้อหาด้านบน = `--section-gap` 72 (มือถือ 56) · ในพื้นเว้นบนก่อนหัวข้อเท่ากัน · ไม่มีกรอบ ไม่มีมุมมน
- บนพื้นนี้: ปุ่มคัดลอกพื้น surface · แถวลิงก์ hover พื้น surface
- หน้า work / case ใช้ footer บนพื้นปกติ (ไม่มีส่วนติดต่อ)

## ส่วนติดต่อ (`#form` · เมนู "ติดต่อ" และปุ่ม "ติดต่อ" ใน hero ชี้มาที่นี่)
1. **ประโยคหลัก** `--display-lg` กว้างสุด 720 `text-wrap: balance` · ใช้ word joiner กันคำไทยตัดกลาง ("อยาก⁠คุย")
2. **อีเมล** 24/500 (มือถือ 20) ขีดเส้นใต้จาง (ชี้ = เข้ม) · `mailto:` · ปุ่ม **"คัดลอก"** pill 32 พื้น muted ไอคอน content_copy → กดแล้ว "คัดลอกแล้ว" ✓ สีตัวอักษรปกติ (ไม่ใช้สีเขียว) 2 วิ · กดด้วยเมาส์ไม่ขึ้นวงโฟกัส · คัดลอกไม่ได้ = "คัดลอกไม่ได้" + ข้อความบอกผู้อ่านหน้าจอ (`aria-live`) · ใช้ Clipboard API แล้วสำรองด้วย execCommand
3. **ปุ่ม Resume** ปุ่มเดียว (filled + ไอคอน download · `download`) สูง 44 ห่างอีเมล 28 · **ไม่มีปุ่ม "ส่งอีเมล"** เพราะอีเมลด้านบนกดส่งได้อยู่แล้ว · ไม่มีบรรทัดสถานะรับงาน
4. **ฝั่งขวา "ช่องทางอื่น"** (กริด 1.4 : 1 ห่าง 56 · เส้นคั่นซ้าย padding 32): หัว 13 text-2 + รายการแถว 48 · ไอคอนทั่วไป 20 text-2 (ไม่ใช้โลโก้แบรนด์: LinkedIn = person · Dribbble = palette) + ชื่อ 15/500 + ↗ ขวา · ชี้ = พื้น muted pill ไอคอนเข้ม ลูกศรขยับเฉียง · เปิดแท็บใหม่และบอกผู้อ่านหน้าจอ · LinkedIn อยู่บนสุด
5. มือถือ: เรียงลง ฝั่งช่องทางอื่นใช้เส้นคั่นบนแทนเส้นซ้าย

## Footer (ทุกหน้า)
- **ลิงก์ทุกหน้า** ระหว่าง © กับ "กลับขึ้นบน": หน้าแรก · ผลงานทั้งหมด · Design system (`.ftr-nav` · หน้าปัจจุบัน `aria-current` ตัว ink) · มือถือ ≤ 600 ลิงก์ขึ้นบรรทัดแรก แล้ว © กับกลับขึ้นบนบรรทัดถัดไป (decisions #97)
