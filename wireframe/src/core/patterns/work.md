# ส่วนผลงาน (portfolio) — v1.6 (2026-10-11)

**กริดแบบ Instagram** (ภาพตั้ง 4:5 ชิดกัน) **+ ชื่อใต้ภาพ** · สลับเป็น**รายการ**ได้ · ค้นหา / กรองหมวด / กรองแท็ก / เรียง ครบ
ตัวอย่าง: `preview/landing-preview.html` § ผลงาน

## แถบเครื่องมือ (แถวเดียว · ตัวกรองรวม)
- หัว: "ผลงาน" + จำนวนที่แสดงอยู่ ("5 ชิ้น" · อัปเดตตามตัวกรอง · `aria-live`) + ป้าย "ข้อมูลตัวอย่าง" ระหว่างที่ชื่อ/ปี/หมวดของผลงานยังแต่งขึ้น (ลบเมื่อใส่ผลงานจริง)
- ซ้ายไปขวา: **ค้นหา** (pill 36 กว้างสุด 320) → **ปุ่ม "ตัวกรอง"** (พื้น muted ไอคอน tune + ตัวเลขจำนวนตัวกรองที่ใช้อยู่ในวงหมึก) → ชิดขวา: **เรียง** "เรียง: ใหม่สุด ▾" (dropdown menu) + **มุมมอง** segmented ไอคอน กริด | รายการ (จำค่าในเครื่อง)
- ค้นหาในชื่อ หมวด แท็ก · คำที่ตรง = ขีดเส้นใต้จาง · Esc ล้าง

### กล่องตัวกรอง
- จอคอม: **popover** ใต้ปุ่ม กว้าง 340 สูงสุด min(480, 70vh) เลื่อนในกล่อง · มือถือ (≤ 720): **sheet** จากล่าง (ขีดจับ · พื้นมืด · สูงสุด 85dvh)
- กลุ่ม (หัวกลุ่ม 12/500 text-2): **เรียงตาม** (เฉพาะมือถือ เพราะซ่อนปุ่มเรียงในแถบ) → **หมวด** (เลือก 1 · มี "ทั้งหมด") → **สถานะ** (ใช้งานจริง / กำลังทำ · กดซ้ำ = ยกเลิก) → **แท็ก** (เลือกได้หลายอัน · แสดง 10 อันที่ใช้บ่อย + "แสดงแท็กทั้งหมด (N)")
- ชิปเป็น filter chip พื้น muted · เลือกอยู่ = พื้นหมึก · มีตัวเลขจำนวนงานถ้าเลือกอันนั้นเพิ่ม · หมวด/สถานะที่ได้ 0 = ปิดใช้ (ยังเห็น) · แท็กที่ได้ 0 = ซ่อน
- **กรองทันทีที่กด** (ไม่ต้องกดยืนยัน) · ท้ายกล่อง: "ล้างทั้งหมด" (text · ปิดใช้เมื่อไม่มีตัวกรอง) + ปุ่มหลัก "แสดง N ชิ้น" = ปิดกล่อง
- ปิด: ✕ · Esc · กดนอกกล่อง (จอคอม) · แตะพื้นมืด / ลากลง (มือถือ) · ปิดแล้วโฟกัสกลับปุ่มตัวกรอง · มือถือ Tab วนในแผ่น
- `role="dialog"` + `aria-labelledby` · ปุ่ม `aria-haspopup="dialog"` `aria-expanded` · `aria-modal` เฉพาะมือถือ

### ตัวกรองที่ใช้อยู่
- แถวใต้แถบ: "กรองอยู่" + input chip พื้นหมึก แต่ละอันมี ✕ ลบทีละอัน + "ล้างทั้งหมด" (เมื่อมี ≥ 2)
- กดแท็กในมุมมองรายการ = เพิ่มแท็กนั้นเข้าตัวกรอง

## มุมมองกริด
- 3 คอลัมน์ (มือถือ 2) ห่าง 28/16 · ภาพ 4:5 มุม 12 · ภาพชิ้นแรกที่แสดงใช้พื้นสีไล่ (จุดเดียวของหน้า) · ชี้ = ภาพยกขึ้น 2px
- **ชื่อใต้ภาพเสมอ** 15/500 + บรรทัดรอง "หมวด · ปี" 13 text-2 · ยังไม่เสร็จ = "กำลังทำ" สีสถานะแทนปี
- ไม่มีกรอบการ์ด ไม่มีแท็กในกริด (แท็กอยู่ในมุมมองรายการ) · ทั้งชิ้นกดได้ผ่านลิงก์ที่ชื่อ

## มุมมองรายการ
- แถว: ภาพย่อ 56 (4:5 มุม 8) · ข้อความ 3 บรรทัดชิดซ้าย: **ชื่อ** 15/500 → **หมวด** 13 text-2 → **แท็ก** (tag 22 กดกรองได้ · ห่าง 6 · ไม่เกิน 3 + "+N") · **ปี หรือ สถานะ** ชิดขวาบรรทัดชื่อ tabular-nums (กำลังทำ = สีสถานะ)
- แท็กไม่วางคอลัมน์ขวา เพราะแท็กเยอะจะเบียดชื่อและตาต้องกระโดดซ้ายขวา · ไม่มีแท็ก = ไม่มีบรรทัดที่ 3
- **ชี้แถว (จอที่มีเมาส์) = ภาพปก 200 ลอยตามเคอร์เซอร์** · ชี้แท็ก/ปุ่ม = ซ่อน (`motion.md` ข้อ 6)
- เส้นคั่นแถว · hover พื้น muted 50% (แท็กยังเห็นชัด) · มือถือโครงเดียวกัน (ภาพย่อ 48 · แท็กตัดลงบรรทัดได้)

## ไม่พบ

- แถวเดียว: ค้นหายืด + ตัวกรอง + มุมมอง · การเรียงย้ายไปอยู่ในแผ่นตัวกรอง · กริด 2 คอลัมน์

## ปักหมุดผลงานเด่น
- ปักได้**ไม่เกิน 3 ชิ้น** · ชิ้นที่ปักขึ้นก่อนเสมอเมื่อเรียง "ใหม่สุด" (ค่าเริ่มต้น) ทุกหมวด · เรียงแบบอื่น = เรียงตามปกติและไม่แสดงหมุด
- กริด: ไอคอนหมุด (`keep` เต็ม) 16 ในวงกลม 28 มุมขวาบนของภาพ พื้น surface 88% + เงา elevation-1 · รายการ: หมุด 16 text-2 หน้าชื่อ
- ข้อความซ่อนสำหรับโปรแกรมอ่านหน้าจอ "ปักหมุด" · ไม่ใช้ป้ายสี "เด่น" "แนะนำ" บนการ์ด

## เมื่อผลงานเยอะ
| จำนวนผลงาน | หน้าแรก | หน้าผลงานทั้งหมด (`preview/work.html`) |
|---|---|---|
| ≤ 12 | แสดงทั้งหมด ไม่มีปุ่ม | ไม่ต้องมี |
| 13–24 | **แสดง 12 + ปุ่ม "ดูทั้งหมด N ชิ้น ▾" / "ย่อ ▴"** (show-hide) · เปิดแล้วหัวส่วนมีลิงก์ "ไปวิธีทำงาน ↓" · ย่อแล้วเลื่อนกลับหัวส่วน (เว้นที่แถบเมนู 64) โฟกัสปุ่ม · เปิดแล้วโฟกัสชิ้นที่ 13 | ไม่ต้องมี |
| > 24 | **แสดง 6 ชิ้น** (ปักหมุดก่อน) ไม่มีแถบเครื่องมือ + ปุ่ม "ดูผลงานทั้งหมด N ชิ้น →" ไปหน้าแยก | แถบเครื่องมือครบ · แสดงทีละ 24 + "แสดงเพิ่ม (N)" + "แสดง 24 จาก 40" · ลิงก์ "← หน้าแรก" เหนือหัวข้อ |

- ค้นหา/กรอง/เรียงใหม่ ไม่ปิดสถานะ "ดูทั้งหมด" ที่เปิดไว้ · ในหน้าแยก = กลับไป 24 ชิ้นแรก
- **หมวด/แท็กเยอะ**: อยู่ในกล่องตัวกรอง จึงไม่ดันแถบเครื่องมือ (แทน chip "อื่นๆ" ของ v1.1)
- **แท็กเยอะ** (รายการ): แสดง 3 แท็กแรก + ปุ่ม "+N" · **ชี้ = tooltip** (สไตล์ tooltip ของระบบ · หน่วง 500ms · โฟกัสคีย์บอร์ดขึ้นทันที) บอกแท็กที่เหลือ · **กด = กางแท็กทั้งหมดในแถวนั้น** แล้วโฟกัสแท็กแรกที่โผล่ · จอสัมผัสไม่มี tooltip แตะ = กาง · `aria-label` "แสดงแท็กอีก N อัน: …"
- **ชื่อยาว**: กริดตัด 2 บรรทัด · รายการตัด 1 บรรทัด …
