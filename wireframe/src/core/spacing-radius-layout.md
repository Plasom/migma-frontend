# Spacing · Radius · Layout — v1 (ล็อกแล้ว 2026-10-10)

| `space-6` | 24 | padding การ์ด (comfortable), gutter desktop |

## 2. Density — สองระดับ
**"เครื่องมือแน่น เนื้อหาโปร่ง"**

| | Compact (เครื่องมือ) | Comfortable (เนื้อหา) |
|---|---|---|
| ใช้กับ | sidebar, nav, ฟอร์ม, รายการ, ตาราง, dropdown, toolbar | การ์ดผลงาน, section, case study, hero, about |
| padding ของกล่อง | 12–16 | 24 (การ์ด) · 40 (กล่องใหญ่) · 64 (hero) |
| gap ระหว่างชิ้น | 8–12 | 16–20 |
| ความสูงแถวในรายการ / เมนู | 36 | — |
| ความสูงช่องกรอก | 40 | 44 (ฟอร์มหน้า contact) |
| ความสูงปุ่ม | 36 (sm 32) | 40 (lg 44) |
| ระยะระหว่าง section | — | 72 desktop · 56 mobile |
| หัวข้อ section → เนื้อหา | 16 | 28 |

## 3. Radius scale — Balanced
| Token | px | ใช้กับ |
|---|---|---|
| `radius-xs` | 4 | focus ring ด้านใน, ชิ้นเล็กมาก |
| `radius-sm` | 8 | เมนูใน sidebar, tag สี่เหลี่ยม, ภาพเล็ก |
| `radius-md` | 12 | ช่องกรอก, กล่องแจ้งเตือน, dropdown, ภาพในการ์ด |
| `radius-lg` | 20 | การ์ด, panel |
| `radius-xl` | 28 | hero, กล่องใหญ่ (case study, ฟอร์ม, CTA) |
| `radius-full` | 999 | ปุ่ม (Pill), chip, badge, avatar |

**กติกามุมซ้อนกัน:** มุมด้านใน = มุมด้านนอก − ระยะขอบ
เช่น การ์ด 20 มีภาพห่างขอบ 8 → ภาพใช้มุม 12

## 4. Layout grid
| ขนาดจอ | ช่วงความกว้าง | คอลัมน์ | gutter | ขอบซ้ายขวา |
|---|---|---|---|---|
| Mobile | < 600 | 4 | 16 | 16 |
| Tablet | 600–839 | 8 | 20 | 24 |
| Laptop | 840–1199 | 12 | 24 | 24 |
| Desktop | ≥ 1200 | 12 | 24 | auto (เนื้อหากว้างสุด 1120) |

- ความกว้างเนื้อหาสูงสุด **1120px** (จัดกลางจอ)
- ความกว้างบรรทัดสำหรับอ่าน (case study) สูงสุด **680px**
- Sidebar: กว้าง **240px** บน laptop ขึ้นไป · ต่ำกว่า 840 ยุบเป็นเมนูด้านบน
- การ์ดผลงาน: desktop 2 ใบใหญ่ (6+6 คอลัมน์) + 3 ใบเล็ก (4+4+4) · tablet 2 คอลัมน์ · mobile 1 คอลัมน์
- จุดกดขั้นต่ำ **44×44px** (Apple HIG) แม้ใน compact

### จังหวะระยะแนวตั้งของหน้า (ใช้ทุกหน้า · 2026-10-11)
| ช่วง | จอคอม | มือถือ (< 600) |
|---|---|---|
| ระหว่าง section (`--section-gap`) | 72 | 56 |
| hero → ส่วนผลงาน (ก้อนเดียวกัน) | 40 | 32 |
| ก่อนพื้นส่วนท้าย + เว้นบนในพื้น | 72 + 72 | 56 + 56 |
| หัวส่วน → เนื้อหาแรก | 20 | 20 |
| ลิงก์ "← หน้าแรก" → หัวหน้า | 16 | 16 |
| เนื้อหาสุดท้าย → เส้น footer | 64 | 48 |
- เลือกจากตารางนี้ก่อนตั้งค่าใหม่ · ระยะภายในชิ้นส่วน (เช่น หัว case → แถวข้อมูล 28) อยู่ในสเปกของส่วนนั้น
- ห้ามบวก padding ล่างของ section เข้ากับ margin ของถัดไป (เคยทำให้ footer ห่าง 144)

## 5. Elevation — แบบ B (เงาอมม่วง นุ่ม) ความเข้ม 60% ✅ (2026-10-10)
เงาใช้สี indigo (54,49,153) แทนดำ เพื่อให้เข้ากับแบรนด์และพื้นเทาเย็น

| Level | ใช้กับ | box-shadow | เส้นขอบ |
|---|---|---|---|
| 0 | พื้นเรียบ, section | none | ตามต้องการ |
| 1 | การ์ดปกติ | `0 1px 3px 0 rgba(54,49,153,.036)` | 1px rgba(228,231,236,.7) |
| 2 | การ์ดตอน hover (+ ยกขึ้น 3px) | `0 10px 24px -6px rgba(54,49,153,.096)` | 1px rgba(228,231,236,.7) |
| 3 | dropdown, popover, toast, tooltip | `0 14px 36px -8px rgba(54,49,153,.132)` | 1px rgba(228,231,236,.7) |
| 4 | modal, dialog, sheet | `0 28px 72px -12px rgba(54,49,153,.204)` | ไม่มี |

- Scrim หลัง modal: `rgba(30,26,80,.36)`
- การ์ดบน Mesh หรือการ์ดที่อยู่บนพื้นขาวไม่ต้องใส่เงา Level 1
- ไม่ใส่เงากับปุ่มและช่องกรอก (ใช้ focus ring indigo-200 แทน)
