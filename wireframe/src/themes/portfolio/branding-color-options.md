## รอบที่ 10 (2026-10-10): Indigo dusk ฉบับใหม่ — ชมพูอมแดงส้ม + blend ให้เนียน
Feedback: ชอบชุด 2 แต่ม่วงกับชมพูควรเข้มกว่านี้ → ชมพูควรออกแดงส้มนิดๆ → ขอให้ blend เข้ากันกว่านี้

**สีหลัก 3 สี:** indigo 363199 → purple 6030CF (hsl 258,62%,50%) → raspberry E44464 (hsl 348,75%,58%)
**สีเชื่อมระหว่างม่วงกับแดง:** 4A31B8 · 8439C6 · AF45C4 · CE46B7

**ทำไมแบบเดิมไม่เนียน:** ม่วงกับแดงห่างกันเกือบ 90° บนวงล้อสี ถ้าไล่ตรงๆ แบบ sRGB ช่วงกลางจะขุ่นและเห็นรอยต่อ
**วิธีแก้:**
- A · Smooth blend: เพิ่มสีเชื่อมโทนม่วงแดงระหว่างทาง + ไล่สีใน OKLab (`linear-gradient(in oklab 135deg, ...)` และใส่แบบ sRGB หลายจุดไว้สำรองสำหรับเบราว์เซอร์เก่า)
  - stops: 363199 0% · 4A31B8 18% · 6030CF 38% · 8439C6 52% · AF45C4 66% · CE46B7 80% · E44464 100%
  - แบบอ่อน: EBEAF5 → EEE8F9 → F7ECF6 → FCEBEE
- B · Mesh glow: ใช้ radial-gradient หลายวงซ้อนกันบนพื้น 6030CF (indigo มุมหนึ่ง, raspberry มุมตรงข้าม, AF45C4 เป็นแสงเสริม)
  - แบบอ่อน: E9E8F6 / FCE6EA / F4E8F8 บนพื้น F7F6FB
